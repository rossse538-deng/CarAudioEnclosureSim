# 车载中音单元逆向分析系统

面向汽车音响改装技师与车友玩家的中音单元箱体、分频辅助分析工具。

输入喇叭 T/S 参数和实际可制作的箱体净容积后，可评估密闭箱容积窗口、计算当前 Fc/Qtc、比较不同分频策略，并给出 LR／BW 高通滤波的模型试调起点。对于容积偏小或谐振阻尼需要重点检查的情况，还会按需给出非周期性阻尼箱（AP）的实验建议。

> 当前版本：**V80**  
> 交付形式：**单文件 HTML**  
> 使用方式：**浏览器本地运行，无需安装、无需业务服务器**

---

## 这个工具解决什么问题

1. **这只中音适合多大的密闭箱？**  
   根据 Fs、Vas、Qts、填充假设和施工上限，给出保守参考、推荐窗口与收益递减参考。

2. **我能做出的这个容积是否合适？**  
   输入倒模总容积，扣除单元、磁路和支架等占位后，按实际净容积计算 Fc、Qtc，并在彩带上显示真实位置。

3. **分频点和高通斜率应该如何选择？**  
   对 BW12／24／48 和 LR12／24／48 六种滤波器进行扫描，分别给出频响探索下限、位移探索下限、综合探索下限与留余量默认起点。

4. **我当前的分频策略是否需要调整？**  
   对比当前设置与同滤波器默认起点，列出频差、标称点合成电平、响应正峰、峰值位移和等效输入余量。

5. **空间受限时能否尝试 AP 箱？**  
   满足触发条件时，显示声阻孔面积、等效孔径和实测步骤；未触发时完全隐藏，不把 AP 当成通用升级方案。

## 快速使用

1. 下载最新发布文件 `车载中音单元逆向分析系统_V80.html`。
2. 使用新版 Microsoft Edge 打开。当前版本已在 Edge 中完成浏览器回归验证。
3. 输入实际单元的 T/S 参数，不要直接沿用演示参数。
4. 输入倒模总容积及全部占位，得到实际净容积。
5. 选择调音目标、滤波器族、阶数／斜率和填充方案。
6. 查看“先看这三项”“容积适用性分析”和“当前实际容积的分频试调建议”。
7. 需要保存结果时，点击“导出分析报告长图”。

**提示：**长图导出使用 CDN 加载的 html2canvas，首次打开页面时需要联网加载该资源。若需完全离线使用，可将该库下载到本地并修改 HTML 中的引用路径。

## 输入参数说明

| 参数 | 单位 | 用途与注意事项 |
|---|---:|---|
| Fs | Hz | 单元自由共振频率 |
| Vas | L | 单元等效容积 |
| Qts | 无量纲 | 单元总品质因数；完整回路参数可用时会进行修正 |
| Re | Ω | 音圈直流电阻，大信号位移估算必需 |
| Pe | W | 模型中的等效正弦输入功率，不等同于音乐功率或厂家额定功率 |
| Xmax | mm | 单向线性位移指标，不是 Xmech，也不代表全面机械安全 |
| Sd | cm² | 有效振动面积，同时用于位移估算和 AP 面积参考 |
| Qes / Qms | 无量纲 | 回路修正与大信号估算所需参数 |
| Rg | Ω | 回路寄生内阻；留空明确按 0 Ω 处理 |
| 倒模总容积 | L | 实际腔体总容积 |
| 单元及支架占位 | L | 单元、磁路、支架等全部占位之和 |
| DSP 高通标称频率 | Hz | 当前准备评估或实际使用的高通频率 |
| 吸音材料方案 | — | 选择对应的 kv、Qb 经验假设 |

实际净容积按以下关系计算：

```text
Vnet = 倒模总容积 − 单元、磁路、支架等全部占位
```

软件中的 3 英寸等参数均为演示值。修改示例单元的关键参数时，示例 Qes／Qms 会被清除，避免把演示值误当作当前单元的实测值继续使用。

缺少大信号必要参数时，软件仍可进行小信号频响分析，但不会生成虚假的位移数值或输入余量。

## 容积彩带与推荐折中容积

### 两种空间策略共用同一声学窗口

“极致声学潜力”和“紧凑空间优先”**不会改变同一个容积的物理性质，也不会生成两套不同的声学窗口**。

两者只改变推荐折中点的位置：

- **紧凑空间优先：**目标位于绿区几何中位略小处，`k = 0.43`。
- **极致声学潜力：**目标位于绿区几何中位略大处，`k = 0.60`。

几何目标按对数容积计算：

```text
V目标 = exp(ln(V低) + k × (ln(V高) − ln(V低)))
```

随后在统一绿区内进行对数容积采样，结合当前滤波器、功率和调音目标复算候选点：

- 有满足默认余量条件的候选时，选择最接近几何目标的实际通过样本。
- 没有完全通过的候选时，只给出容积折中，并明确提示分频或位移条件尚未全部通过。
- 推荐窗口不可达时，不输出推荐折中点。

**推荐折中容积不是唯一物理最优，也不是厂家指定容积。**

### 彩带读数原则

- 彩带、当前指针、推荐标记和刻度共用同一真实容积坐标。
- 尺度会根据当前容积、硬上限和推荐点自动调整。
- 平滑过渡只用于表达物理变化的连续性，不会移动数值边界。
- 绿色仅表示符合当前小信号容积参考，不代表音质、分频或机械安全已经合格。
- 超出推荐窗口不等于单元必然损坏，低于参考也不等于物理禁区。

## 分频分析逻辑

### 支持的滤波器

| 滤波器族 | 阶数／斜率 | 标称点电平 |
|---|---|---:|
| Linkwitz–Riley（LR） | 2／4／8 阶，12／24／48 dB/oct | 约 −6.02 dB |
| Butterworth（BW） | 2／4／8 阶，12／24／48 dB/oct | 约 −3.01 dB |

DSP 滤波器的 LR／BW 类型，不等于最终声学响应天然具有同名斜率或同样电平。软件会计算箱体与 DSP 的合成响应，而不是仅按 Fs 倍率给出一个分频点。

### 四种扫描结果

- **频响探索下限：**满足当前小信号响应条件的最低扫描点。
- **位移探索下限：**满足当前位移条件的最低扫描点；大信号参数不全时不启用。
- **综合探索下限：**同时满足已启用频响与位移条件的最低扫描点。
- **留余量默认起点：**在综合条件之外，再满足额外通带和位移余量要求的试调起点。

扫描步长为 5 Hz。探索下限与默认起点分开报告，避免把“模型刚达到边界”误当成适合直接实装的调试起点。

调音目标包括：

- 向下延伸优先
- 平衡优先
- 高声压、低失真优先

调音目标改变分频筛选阈值与提示，不改变当前箱体的 Fc／Qtc，也不移动统一容积窗口。

## 非周期性阻尼箱（AP）建议

AP 方案是**条件触发的实验选项**，主要适用于：

- 实际净容积低于保守或推荐参考；
- 推荐容积在施工上限内不可达；
- 密闭模型 Qtc 较高，谐振阻尼需要重点检查。

当 Sd 有效时，软件给出总开孔面积 `15%～20% × Sd` 的实验起点，并换算等效单圆孔直径。该面积属于经验实验值，不是通用成品尺寸。

AP 使用声阻孔和阻尼织物，**不是低音反射管**，不能套用导管长度调谐公式。改造后必须重新测量阻抗与近场频响，不能继续沿用密闭模型的 Fc／Qtc 作为 AP 结果。

## 核心计算口径

密闭箱基础模型：

```text
Veff = Vnet × kv
α = Vas / Veff
Fc = Fs × √(1 + α)
Qtc = 1 / [(1 / √(1 + α)) × (1 / Qts) + 1 / Qb]
```

其中：

- `kv`：吸音填充带来的等效容积修正；
- `Qb`：箱体损耗的经验修正；
- `Fc`：密闭箱共振频率；
- `Qtc`：密闭箱总品质因数。

容积窗口包含 Fc、Qtc、α 与施工上限等工程参考。详细阈值集中在 HTML 的 `PhysicsEngine.CROSSOVER_CONFIG` 与 `solveSystemBounds()` 中，便于审核和后续标定。

合成响应采用箱体响应与 DSP 高通响应的乘积；对数 dB 域中表现为相加。早期滚降检查会分别列出箱体附加衰减、滤波器衰减和合成结果，避免把滤波器的正常滚降误判为箱体不兼容。

## 模型边界

本工具用于方案筛选和试调起点规划，不替代实车测量。以下因素没有被完整建模：

- 音圈电感、热压缩及温度变化；
- 悬挂、磁路和其他非线性；
- 箱体泄漏、真实填充流阻和腔体模态；
- 安装位置、车门／A 柱结构和车厢边界增益；
- 其他单元的频响、相位、灵敏度与时间对齐；
- 实际音乐的频谱、峰值因数和长期热状态。

空气弹簧二次谐波只表示单一非线性来源的趋势，不是单元总 THD 或实车失真。Xmax 余量也不能证明热、引线或全面机械安全。

最终分频、真实失真、结构模态、AP 声阻和安全性仍需通过阻抗、频响、位移／失真及实车试听验证。

## V80 主要更新

- 统一两种空间策略的声学窗口，消除窗口不相交和颜色口径不一致的问题。
- 彩带恢复平滑过渡，所有渐变节点保持真实坐标。
- 增加动态尺度与易读刻度，兼容极窄窗口和大容积。
- 将“最佳容积”调整为“推荐折中容积”，引入对数目标与实际候选复核。
- 推荐标记直接嵌入彩带，不再使用外部白色菱形。
- 精简低价值模块和结构输入，保留核心摘要、容积彩带、分频建议与条件式 AP 方案。
- 清理讨论式界面文字，详细模型判据默认折叠。
- 修复窄屏布局、折叠说明导出及 HTML／CSS 起始标记问题。
