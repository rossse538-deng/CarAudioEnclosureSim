## 📌 项目背景与解决的痛点

在传统的汽车音响 A 柱/三角位中音倒模施工中，改装店大多依赖“师傅手艺与经验”盲猜容积。然而：
1. **空间与声学的矛盾**：A 柱视野与安装深度极其有限，箱体往往做不到家用音响的理论容积。
2. **DSP 主动分频工况的特殊性**：中音单元在车内普遍采用 DSP 高通滤波（HPF），传统无源音箱“死磕单一 Qtc=0.707”的公式已不再适用。
3. **极端单元适配困难**：如丹拿等超低 Qts（强磁通）单元，套用旧公式常算出脱离物理现实的微型容积。

本系统旨在**打破传统经验主义**，通过严谨的电声传递函数卷积、绝热空气非线性失真模型及结构力学分析，**量化车内容积妥协带来的声学代价，并给出理性的倒模容积区间与 DSP 补偿指引。**

---

## 🚀 V52.0 核心功能与物理引擎

### 1. 真实声学传递函数与 DSP 卷积分析
* **双二阶声学高通模型**：精准计算箱体闭箱后的真实谐振频率 Fc、品质因数 Qtc 以及谐振隆起峰值。
* **Linkwitz-Riley / Butterworth 真实滤波器衰减**：精确串联 DSP 高通滤波器幅频曲线，预判机械谐振峰穿透通带的能量残留（Resonance Leakage），杜绝中频声染色。

### 2. 物理与失真硬约束（解决微型容积误区）
* **空气弹簧绝热非线性失真（THD2）估算**：引入 Delta V / V 绝热压缩比判定，防止小箱体内空气变硬导致的偶次谐波失真。
* **物理安全底线容积表**：结合结构深度、振膜冲程与滤波抑制，给出不同滤波器斜率下“不可突破的物理安全下限”。

### 3. 推荐黄金容积区间（[V_min ~ V_max]）
* **下限点**：保障频响平坦度与基本瞬态控制。
* **上限点（边际效益拐点）**：明确指出容积增大至何处时声学收益已达 95% 以上，防止盲目追求超大容积而牺牲车内视野。

### 4. 3D 打印与倒模结构力学评估
* 内置 **PLA / PETG / ASA / CF-Nylon** 材料力学库。
* 板件最低阶自振频率（f_panel）预估与避让检测，防止箱体壳体在中音工作频段内共振。
* 异形曲面、切片模糊表皮（Fuzzy Skin）及阻尼胶涂抹的刚度加成量化。

### 5. 专家级 AP 声阻泄压箱（Aperiodic Enclosure）方案
* 针对高 Qts 单元在 A 柱空间受限时的工况，自动触发非周期性阻尼孔设计指引，释放过量空气阻尼。

### 6. 一键工程报告生成
* 集成 html2canvas 与 Chart.js，一键导出高清雷达图、五维声学打分与施工建议长图，便于与车主沟通方案。

## 🛠️ 输入参数说明

| 模块 | 参数项 | 说明 |
| :--- | :--- | :--- |
| **容积条件** | 逆向建模净容积 (V_cad) | 3D 建模或量筒灌水测得的纯空腔体积（升） |
| | 单元磁钢占位 (V_driver) | 扬声器磁体及盆架排开的物理体积（升） |
| | 声学填充方案 | 纯空箱 / 贴壁吸音 / 标准蓬松填充 / 高密填充 |
| **单元参数** | T/S 参数 (Vas, Qts, Fs) | 扬声器厂家公布或 Clio/DATS 实测小信号参数 |
| | 大信号参数 (Xmax, Sd, Re, Pe) | 线性位移、有效振动面积、直流电阻、额定功率 |
| **DSP 方案** | 计划分频点与滤波器斜率 | 目标高通切频 (Hz) 及滚降斜率 (12~48 dB/oct) |
| **结构工艺** | 打印壁厚、面板跨度、材料 | 壳体厚度、受力最大跨度及打印耗材类型 |

## 📊 雷达图五维评价体系

1. **瞬态与解析**：系统力学阻尼特性，Qtc <= 0.707 得高分，欠阻尼过冲拖尾扣分。
2. **分频匹配度**：评估通带平坦度及箱体谐振是否被 DSP 彻底衰减。
3. **动态承载力**：额定功率下振膜冲程与大信号位移安全裕量。
4. **结构与背波**：壳体自振刚度、背波反射深度及小容积空气非线性失真。
5. **空间利用率**：实际倒模容积相对推荐黄金区间的适配度与车内空间利用合理性。
