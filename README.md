# 车载中音单元逆向分析系统 V35 (Acoustic Matrix)

车载中音单元逆向分析系统是一款基于纯前端静态技术（HTML5 / CSS3 / JavaScript）构建的专业电声与箱体物理力学评估工具。本系统旨在辅助汽车音响改装店技术人员、电声工程师及 DIY 爱好者，在针对中音喇叭进行 3D 扫描、倒模箱体建模设计前，提供量化的声学阻尼、结构刚性以及 DSP 策略的可行性评估。

## 📥 快速开始

本系统为单文件绿色版结构，无需安装任何后端依赖或数据库。
1. 下载 `index.html` 文件至本地。
2. 双击在任意现代浏览器（Chrome, Edge, Safari, Firefox 等）中打开即可使用。
3. 亦可直接托管至 GitHub Pages 等静态托管平台。

## 🛠️ 核心功能模块

### 1. 逆向容积与声学等效计算
* **物理净容积计算**：支持输入逆向建模的纯空腔体积，并扣除单元磁钢及支架的实际物理占位容积。
* **填充系数动态换算**：提供 4 种声学吸音棉填充方案（纯空箱、仅贴壁、标准填充、高密填充），基于热力学等温膨胀物理效应，动态折算箱体的实际等效声学容积，并给出建议的吸音棉克重范围。

### 2. 7级高颗粒度 Qtc 声学特性评估 (V35 核心迭代)
系统摒弃了含糊的主观听感形容词，完全基于电声总品质因数（Qtc）物理模型，将箱体阻尼状态划分为 7 个高颗粒度、客观严谨的技术判定等级：
* **1级：深度过阻尼 ($Q_{tc} < 0.50$)** —— 系统阻尼过高，物理气垫约束力缺失，存在大动态物理拍边与撞摆过载风险。
* **2级：轻度过阻尼 ($0.50 \le Q_{tc} < 0.65$)** —— 系统瞬态收尾迅速，但中低频能量释放略显不足。
* **3级：标准平坦阻尼 ($0.65 \le Q_{tc} \le 0.75$)** —— 高保真理论平衡点，频响平直无明显多余染色，接近经典巴特沃斯 0.707 响应。
* **4级：轻度欠阻尼 ($0.75 < Q_{tc} \le 0.85$)** —— 气垫保护与能量聚焦的良好结合点，大动态力学稳定性佳。
* **5级：中度欠阻尼 ($0.85 < Q_{tc} \le 1.00$)** —— 典型车载紧凑空间妥协区间，谐振频率（Fc）附近有轻微能量堆积，需配合 DSP EQ 进行平坦度修正。
* **6级：重度欠阻尼 ($1.00 < Q_{tc} \le 1.20$)** —— 空腔谐振严重，产生高能谐振峰，时域余振尾音迟滞并易诱发内饰板机械共振。
* **7级：极度欠阻尼 ($Q_{tc} > 1.20$)** —— 系统物理失效，声能严重堆积在窄带谐振区，物理结构无法满足高还原度要求。

### 3. DSP 分频策略与 EQ 参数预判
* **物理位移限制点**：计算 1.5 倍 Fc 的临界工作下限，并对在此频点下的高阶陡峭分频斜率给出警告和约束性说明。
* **高保真安全频点**：计算 2.0 倍 Fc 的推荐工作频点，在此状态下互调失真（IMD）低，允许使用平缓的交越斜率。
* **专家级 AP 泄压对策**：针对高 $Q_{ts}$ 单元在极小容积下的声学困境，提供非周期性阻尼设计（Aperiodic Enclosure）的工艺尺寸指引。

### 4. 结构力学刚度与谐振风险评估
* **多材料刚性折算**：涵盖 PLA/PETG、ABS/ASA 以及碳纤维尼龙（CF-Nylon）等不同杨氏模量的切片耗材。
* **工艺补偿计算**：综合评估打印壁厚、几何构型（平面 vs 异形曲面）以及表面工艺（模糊表皮、阻尼胶涂抹）对结构谐振频率的提升贡献。
* **安全比率（Safety Ratio）**：根据 Qtc 反向空气压力载荷与箱体物理强度的比值，计算腔体防共振安全阈值，并给出具体的壁厚增加或涂层改进建议。

### 5. 多维可视化反馈
* **声学雷达图谱**：结合 `Chart.js`，将复杂的阻尼状态抽象为“瞬态与解析”、“低频下潜”、“动态承载力”、“频响平坦度”和“声段衔接度”五个经典物理指标的极坐标图形。
* **一键无损截长图**：集成 `html2canvas` 库，支持一键将当前分析面板的所有计算数据、雷达图谱及专家结论，截取生成一份高分辨率的 PNG 声学评估报告长图。

## 🔬 声学与工程免责声明

本系统所输出的所有数值计算、分频点推荐、阻尼特性判定均基于**经典 T/S 参数电声理论物理模型（且处于理想的无限大障板或密封测试空腔环境）**。

在实际车载复杂空间环境中：
1. **声学边界变化**：受仪表台局部反射（号角效应）、前挡玻璃折射、A柱几何声学耦合以及复杂的车内驻波干涉，系统的实际截止频率、声阻抗曲线以及离轴衰减特性会与理论模型产生明显偏差。
2. **测试与听感**：系统所提供的各项 DSP 参数和曲线评估，不应作为唯一的施工与最终调音依据。在实际施工完成后，**务必使用 RTA 声学测试麦克风测量实际车内频响曲线，并以最终人耳实际听感判定为准。**
