## 📌 项目简介 (Overview)

在汽车音响改装倒模（A柱/仪表台/三角板）过程中，受限于狭小的车内空间，中音单元通常很难获得理想的理论箱体容积。过去的调音师与改装师往往只能“凭经验猜测”容积偏差对声音的影响。

**车载中音单元逆向分析系统** 是一款纯前端运行的专业电声工程评估工具。只需输入单元 T/S 参数、倒模建模净容积与拟使用的 DSP 有源分频方案，系统即可通过**真实的二阶密闭箱传输函数与 DSP 滤波器传递函数**进行级联扫频求解，精准预测箱体谐振峰在分频带内的残留电平，并给出结构力学与大信号冲程校验。

## 🚀 V51.0 核心突破 (What's New in V51.0)

相比早期的传统 $Q_{tc}=0.707$ 固化评估模型，V51.0 实现了**电声算法与 DSP 主动分频逻辑的全面进化**：

1. **真实传递函数级联扫频引擎**：
   * 彻底废除理想化的折线直线渐近近似，改用二阶密闭箱声学传递函数 $H_{box}(s)$ 与真实的 DSP 滤波器传递函数 $H_{dsp}(s)$（Linkwitz-Riley / Butterworth）在频域内进行连续离散化级联扫频。
2. **现代车载 DSP 主动分频对齐**：
   * 引入“分频匹配度”概念，核心评估“箱体固有谐振经 DSP 滤波后是否仍穿透通带造成可闻隆起”，完美解释并支持了低 $Q_{ts}$ 顶级单元（如丹拿、Brax 等）在广阔容积（0.5L~4.0L）下的极高声学宽容度。
3. **动态 $Q_{tc}$ 视觉健康度判定系统**：
   * 采用重构的色阶映射逻辑：$Q_{tc} \le 0.85$（高保真/临界阻尼/低 $Q_{ts}$ 宽容区）显示高亮绿色；$0.85 < Q_{tc} \le 1.10$ 显示预警黄色；$Q_{tc} > 1.10$ 显示危险红色。
4. **大信号位移与空气非线性风险预警**：
   * 结合额定功率、输入阻抗及 DSP 滤波后的实际位移，比对箱体等效深度，提供克制且务实的空气弹簧非线性比例风险提示。

## 🧮 电声学数学模型 (Acoustic Mechanics)

系统内部集成的物理求解引擎遵循以下电声学基本方程：

### 1. 密闭箱二阶高通传递函数
$$|H_{box}(f)|^2 = \frac{(f / F_c)^4}{\left(1 - (f / F_c)^2\right)^2 + \frac{(f / F_c)^2}{Q_{tc}^2}}$$

其中 $F_c = F_s \cdot \sqrt{\frac{V_{as}}{V_{eff}} + 1}$，$Q_{tc} = Q_{ts} \cdot \sqrt{\frac{V_{as}}{V_{eff}} + 1} \cdot Q_{loss}$。

### 2. DSP 级联滤波器传输函数 (Linkwitz-Riley / Butterworth)
* **偶数阶（2/4/6/8阶，如 LR4）**：在分频点处固有 $-6\text{dB}$ 幅值衰减。
* **奇数阶（1/3/5阶，如 BW3）**：在分频点处固有 $-3\text{dB}$ 幅值衰减。

### 3. 系统级联残留电平扫频 (System Residual Sweep)
在给定频段内自动搜索最大残留电平：
$$\text{Residual}(f) = 10 \log_{10}|H_{box}(f)|^2 + 20 \log_{10}|H_{dsp}(f)|$$
当 $\text{Residual}_{max} \le 0\text{dB}$ 时，判定箱体谐振已被 DSP 充分压制在平坦通带以内。

## ✨ 核心功能模块 (Features)

* 📦 **逆向容积与吸音棉模拟**：自动扣除磁钢占位体积，支持纯空箱、仅贴壁、标准填充、高密填充等多孔材质热力学/机械阻尼修正。
* 🎛️ **DSP 方案离散求解**：根据目标分频点与滤波器斜率（12~48 dB/oct），利用数值二分法自动反推**安全所需最小净容积矩阵**。
* ⚡ **大信号物理极限校验**：输入 $X_{max} / S_d / R_e / P_e$，实时估算在 DSP 保护下的 $F_c$ 处振膜滤波位移，防止大动态拍边过载。
* 🏗️ **3D 打印力学与外壳刚度评估**：基于材料弹性模量（PLA / PETG / ASA / CF-Nylon）与几何双曲面刚度修正，计算面板自振基频 $f_{panel}$，避让中音工作主频带。
* 📊 **五维纯声学雷达图**：从瞬态与解析、分频匹配度、动态承载力、结构与背波、容积紧凑度五个维度进行定量打分。
* 📸 **一键报告导出**：内置 `html2canvas` 引擎，支持一键将评估报告渲染导出为 2K 高清 PNG 长图。

## 🛠️ 使用方法 (Getting Started)

本系统采用**单文件零依赖（Single-file HTML）架构**，无需安装任何 Node.js 编译环境，即开即用：

1. **直接运行**：
   下载项目中的 `index.html`（或直接使用版本文件），在任意现代浏览器（Chrome / Edge / Safari / Firefox）中双击打开即可。
2. **部署至 GitHub Pages**：
   Fork 本仓库后，在仓库设置中开启 **GitHub Pages**，即可获得专属的移动端/PC端在线评估工具。
