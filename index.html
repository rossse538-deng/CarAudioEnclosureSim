💡 程序设计逻辑与工程巧思
本系统专为解决车载 A 柱 3D 倒模与有源分频联动而设计，核心巧思在于：
• 容积边界为单元固有属性，与分频点/功率完全解耦（V77 起）：推荐区间只由单元 T/S 参数决定，不随分频点或功率设置浮动——物理安全底线 = Fc ≤ 2.5×Fs（抗压缩极限）且 Qtc ≤ 1.25（谐振峰 ≤+2.7dB）；推荐下限 = Fc ≤ 2.0×Fs（空气弹簧刚度 ≤3×悬挂刚度）且 Qtc ≤ 0.90；推荐上限 = Qtc ≤ 0.78 与 α ≤ 1.25 收益饱和点的较大者；收益饱和界限 = Qtc ≈ 1.1×Qts。分频点与功率的角色收敛为两项：① 工况安全评估——区间确定后，按当前功率/分频点/斜率核算区间端点的峰值位移与失真，超标时给出提示与缓解路径，但不反向修改推荐容积；② 兼容性输出——"箱体定 Fc、Fc 定最低分频点"，当前分频点不满足衔接要求时给出警告。任何固有目标在 A 柱施工上限内不可达时，系统显式声明无解并给出 AP 泄压等对策，不输出伪精确数字；
• 策略双通道（V75 起）：安全底线与完整声学目标不随策略移动，策略只改变推荐窗口的收束——紧凑空间优先：下限向底线方向扩展（最多至完整下限的 0.85 倍，代价是 Qtc/Fc 定位裕量减小，flags 中显式声明）、上限收束为完整下限的 1.25 倍；极致声学潜力：上限延伸至 α≤0.55 阻尼饱和带（Fc≈1.25×Fs，接近自由场负载）；
• 单元参数特征解读（V73.1 起）：按"参数事实 → 工程推断 → 判断边界"三层输出解读卡——Qts/Vas/Fs/EBP 客观分档、Qts×Vas 联合设计取向推断、主频段甜区与分频试调建议，全部阈值标注为经验分档；推荐窗口宽度小于实用施工容差时显式声明"设计窗口过窄"，不输出伪精确单点；
• 全频段残余峰评估：对"密闭箱响应 × 高通滤波器"的合成传递函数做全频扫频，以最大残余隆起作为带内泄漏指标，取代单点估算；
• 全频段大动态冲程追踪：扫频求解最大振膜机械位移（扫频上限取 2.5×分频点 与 2.2×Fc 的较大者），客观评估非线性失真与振幅过载边界；
• 车用物理边界收敛：按单元尺寸设定 A 柱施工容积上限，所有边界在该硬约束内求解；
• 填充系数保守化（V74 起）：吸音材料等效膨胀系数 kv 改为 1.03 / 1.08 / 1.12 的保守口径（原 1.06 / 1.12 / 1.18）——宁可容积估算略偏保守，也不以偏大的等效膨胀制造虚假余量；kv 与箱体损耗 Qb 均为未标定经验估值。
📐 核心机电与物理方程
1. 回路修正阻尼：Ret = Re + Rg, Qes' = Qes · (Ret / Re), Qts' = (Qms · Qes') / (Qms + Qes')（Qms 可留空，按 4.2 估算）
2. 密闭箱状态方程：Veff = Vnet · kv, α = Vas / Veff, Fc = Fs · √(α + 1), 1/Qtc = 1/(Qts'·√(α+1)) + 1/Qb
3. 机电峰值冲程：|X(f)| = [Vin · BL / (Ret · Mms · √((ωc² - ω²)² + (ω · ωc / Qtc)²))] · |Hfilter(f)|
